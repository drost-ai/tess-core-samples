# Tess Core samples

Small, complete programs built on [Tess Core](https://github.com/drost-ai/tess-core), the
agent runtime for Python. Each folder is one sample you can run in a few commands and read
in one sitting.

| Sample | What it is |
|---|---|
| [coding-agent-minimal](coding-agent-minimal/) | A terminal coding agent in one file: multi-turn chat, live tool calls, sub-agents, resume. |

Every sample has its own `pyproject.toml`, so `uv sync` in its folder is all the setup
there is. The [Tess Core documentation](https://continuityresearch.ai/tess-core/docs) covers
the runtime itself.
